# Record editing change

The records page now lets a user rename an existing record.

Expected behavior:

- Saving a non-empty name shows the record with its new name.
- Reloading the detail page keeps the new name.
- Submitting an empty name stays on the form and shows a validation error.
- The records list link opens the record detail page.

Check the visible outcome after each action. If the requirement does not define
what a value should be, leave that assertion UNVERIFIED instead of guessing.
