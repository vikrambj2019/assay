# Profile editing (Driftline demo)

A signed-in user can update their contact details on the Account page.

Expected behavior:

- After signing in, the user lands on the Account page.
- Changing the mobile phone number and choosing "Save changes" shows a
  confirmation.
- Reloading the Account page still shows the new phone number.
- A phone number with fewer than 10 digits is rejected with an error and is
  not saved.

Check the visible outcome after each action. If a requirement does not define
an exact value, leave that assertion UNVERIFIED instead of guessing.
